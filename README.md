 # Wine Quality Prediction using Linear Regression

## Project Overview
This project uses Machine Learning and Linear Regression techniques to predict wine quality based on various chemical properties of wine.  
The project includes Exploratory Data Analysis (EDA), data visualization, model training, prediction, and performance evaluation.

---

## Objectives
- Analyze wine dataset using EDA
- Visualize feature relationships
- Train a Linear Regression model
- Predict wine quality values
- Evaluate model performance using graphs
